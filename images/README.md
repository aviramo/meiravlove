# תמונות

כל מקום לתמונה באתר הוא מסגרת מקווקוות עם שם הקובץ הצפוי (למשל `images/hero-meirav.jpg`).
כדי להכניס תמונה: שמרו אותה בתיקייה הזו בדיוק בשם המצוין, והיא תחליף את המסגרת אוטומטית.
אין צורך לגעת בקוד. מומלץ JPG/WebP, עד ~300KB לתמונה, ו־`og-share.jpg` (1200×630) לשיתוף ברשתות.

שמות הקבצים נמצאים בכל מסגרת באתר. רשימה מלאה: `grep -oh 'images/[a-z0-9-]*\.jpg' *.html | sort -u`

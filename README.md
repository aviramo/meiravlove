# האתר של מירב מאור

אתר סטטי בעברית (מימין לשמאל). אין שרת ואין תלויות: אפשר לפתוח את `index.html` בדפדפן או לפרסם ב-GitHub Pages.

## מבנה

| קובץ | מה זה |
|---|---|
| `build.py` | מייצר את כל עמודי ה-HTML מחלקים משותפים (הדר, תפריט, פוטר, פתיח, מסגרות תמונה, תבנית למרחבים) |
| `style.css` | כל העיצוב, באתר אחד לכולם. ארבעת גדלי הטקסט מוגדרים ב-`--t1` עד `--t4` |
| `site.js` | תפריט, אנימציות מעבר בין עמודים, הצטמצמות ההדר בגלילה, סרטון הפתיח |
| `images/` | תמונות וסרטון. ראו `images/README.md` |

## איך עורכים

1. **טקסט, הדר, פוטר, תפריט, או עמוד:** עורכים את `build.py` ואז מריצים:

   ```
   python3 build.py
   ```

   הפקודה כותבת מחדש את קבצי ה-HTML. לא עורכים את קבצי ה-HTML ביד, כי ההרצה הבאה תדרוס את השינוי.
2. **עיצוב:** עורכים את `style.css` ישירות. אחרי שינוי ב-`style.css` או ב-`site.js` מריצים `python3 build.py` כדי שהדפדפנים יטענו את הגרסה החדשה.
3. **תמונות וסרטון:** שומרים בתיקיית `images/` בשם שמופיע במסגרת באתר (למשל `hero-video.mp4`).

## עדיין חסר

- טופס יצירת הקשר לא שולח הודעות, וצריך לחבר אליו שירות טפסים.
- נוסח סופי לסיפור האישי ולמדיניות הפרטיות (מסומנים בצהוב באתר).
- תמונות וסרטון אמיתיים, ופרטי אירועים.
